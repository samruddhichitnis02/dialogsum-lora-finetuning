# AI Use Disclosure

## Overview

AI tools were used as development and learning assistants during this project. The final implementation was executed, tested, and validated locally in Jupyter Notebook on an NVIDIA RTX 3060 GPU.

## How AI Was Used

AI assistance was used for:

- Explaining FLAN-T5, sequence-to-sequence summarization, and LoRA.
- Suggesting code structure for data preparation, tokenization, fine-tuning, inference, and evaluation.
- Helping debug Python, PyTorch, Transformers, PEFT, and Trainer errors.
- Suggesting memory-safe evaluation techniques for a 6 GB GPU.
- Explaining ROUGE metrics and interpreting evaluation results.
